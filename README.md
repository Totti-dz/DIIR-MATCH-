# DIIR MATCH — حجز ملاعب السوقر

## تشغيل محلي
    npm install
    npm run dev

## رابط تحميل APK (مرة واحدة فقط)
1. أنشئ مستودعاً على GitHub وارفع هذا المجلد (بدون ACCESS_CODES.txt — موجود في .gitignore).
2. في index.html غيّر `APK_URL` إلى:
   `https://github.com/اسم_المستخدم/اسم_المستودع/releases/latest/download/diir-match.apk`
3. كل push يبني التطبيق تلقائياً (تبويب Actions) وينشر APK في Releases.
   الرابط أعلاه ثابت ويشير دائماً لآخر نسخة.

## آيفون
iOS لا يقبل APK. افتح الموقع في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
